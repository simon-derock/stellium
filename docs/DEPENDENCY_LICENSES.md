# Dependency License Review

CI installs the locked dependency graph and retains a JSON inventory generated by `pip-licenses` for 90 days. The inventory includes transitive and development dependencies, so it may include packages that are not shipped as part of Stellium itself.

The inventory is an audit input, not an automatic legal approval. In the measured local environment, `mistralai` and `cuda-toolkit` reported `UNKNOWN` metadata, while Torch's transitive NVIDIA CUDA packages reported proprietary license labels. Review these entries against the relevant upstream license texts before redistribution or deployment that bundles those packages. Do not treat missing package metadata as permission.

Stellium itself declares MIT in `pyproject.toml`, matching the repository `LICENSE` file. The project does not yet enforce a broad allowlist: dual-licensed packages, platform-specific dependency markers, and proprietary accelerator runtimes need explicit review before a defensible policy can be enforced.
